# Scenarios MOC

This map collects practical scenarios where harness engineering, loop engineering, and graph engineering are applied to solve real-world problems in agentic software development.

## Scenario Collection

### [[Production Coding Agent]]
Designing a reliable coding-agent workflow for production applications.

### [[Vibe Coding Workflow]]
Simplified setup for exploration and rapid prototyping.

### [[Autonomous Development Workflow]]
Hands-off agent operation for well-defined tasks.

### [[Multi Agent Development]]
Team-based agent collaboration for complex systems.

### [[Feature Implementation]]
Building a feature in an existing repository using harness + loop + graph engineering.

### [[Wrong File Modification]]
Solving the problem of Claude Code modifying the wrong files.

### [[Verification Gap]]
Designing appropriate loops when Claude Code writes code but doesn't verify it.

### [[Research Agent]]
Creating a workflow for Claude Code to research technical topics and produce documentation.

### [[Autonomous Test Fixer]]
Building an agent to autonomously fix failing tests.

### [[Skill Router]]
Designing a graph/skill-routing architecture for deciding which skills to use from a set of 20 reusable skills.

## How to Use Scenarios

Each scenario file contains:
- **Problem Statement**: Clear description of the situation
- **Engineering Application**: How harness, loop, and graph engineering concepts are applied
- **Claude Code Implementation**: Specific configuration and components
- **Why It Works**: Explanation of the effectiveness
- **Failure Modes**: Potential issues and how to mitigate them
- **Adaptations**: How to modify for different contexts
